# Simple Jump Game

A fast-paced, browser-based side-scroller built with Vue.js. Dodge the red obstacles to increase your score!

## 🎮 How to Play
- **Spacebar**: Jump over the incoming obstacles.
- **Goal**: Survival is key. The longer you last, the higher your score climbs.
- **Game Over**: If you hit an obstacle while on the ground, the game ends.

## 🚀 Features
- **Real-time Collision Detection**: Precise hitboxes to determine win/loss states.
- **Dynamic Scoring**: Track your performance in real-time.
- **Responsive Loop**: Smooth animations powered by `requestAnimationFrame`.
- **Clean UI**: Minimalist design focused on gameplay.

## 🛠️ Tech Stack
- **Framework**: Vue.js 3
- **Styling**: CSS3 (Transitions & Flexbox)
- **Logic**: JavaScript (ES6+)

## 💻 Project Setup

If you are running this as a Vue CLI or Vite project:

1. **Clone the repository**
   ```bash
   git clone https://github.com
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Compiles and hot-reloads for development**
   ```bash
   npm run dev
   ```

4. **Compiles and minifies for production**
   ```bash
   npm run build
   ```
